# Processed Data Directory

This directory contains cleaned, filtered, and analysis-ready datasets derived from the raw source files in [`01_raw_data/`](../01_raw_data/). All files here are generated outputs — see [`03_processing_scripts/`](../03_processing_scripts/) for the notebooks that produce them.

## Files

### EPD Data

#### EC3 EPD Data

| File | Description | Records | Generated by |
|------|-------------|---------|--------------|
| `epd_data_cleaned_all.pkl` | All US concrete EPDs after cleaning: flattened JSON, unit normalization, IQR outlier removal, filtered to post-2020 EPDs | 69,305 | `ec3_concrete_data_cleaning.ipynb` |
| `epd_data_all.csv` | CSV export of all cleaned EPDs with valid GWP values | 69,305 | `ec3_concrete_filtering_all.ipynb` |
| `epd_data_fly_ash.csv` | Subset filtered to EPDs with fly ash content | — | `ec3_concrete_filtering_scm.ipynb` |
| `epd_data_fly_ash_or_ggbs.csv` | Subset filtered to EPDs with fly ash and/or GGBS content | 4,745 | `ec3_concrete_filtering_scm.ipynb` |
| `active_concrete_plants_ec3.csv` | Deduplicated list of unique concrete plants with coordinates and EPD count, filtered to the continental US using a point-in-polygon test against Natural Earth country boundaries | — | `ec3_concrete_plant_list.ipynb` |

#### Broyles EPD Data

| File | Description | Records | Generated by |
|------|-------------|---------|--------------|
| `broyles_epd_data_cleaned.csv` | Broyles dataset after cleaning: column selection, GWP per CY conversion, SCM boolean flags (`contains_fly_ash`, `contains_slag`), strength filter (≥ 2,000 psi), and IQR outlier removal globally and per strength bucket | 44,327 | `broyles_epd_data_processing.ipynb` |

**Notes on EPD data:**
- GWP values are normalized to **kgCO2e per cubic yard** for cross-EPD comparability
- Compressive strength is converted to **psi** and rounded to the nearest 500 psi; represents the final (design) strength using the larger of `concrete_compressive_strength_28d` and `concrete_compressive_strength_other` to capture mixes that reach full strength after 28 days
- Outliers are removed using an IQR method applied globally and then per compressive strength bucket
- The `.pkl` format is used for efficient reload in downstream notebooks; use the `.csv` files for general-purpose access

### Coal Plant Data

| File | Description | Records | Generated by |
|------|-------------|---------|--------------|
| `active_coal_plants_US.csv` | Active (operating) coal-fired power plants in the US, with location, capacity, and ownership data | — | `coal_plant_data_filtering.ipynb` |

| `concrete_plant_closest_coal_distances.csv` | Per-plant road distance (miles) to the nearest coal plant, with NRMCA region assignment. Pre-computed to avoid re-running the OSRM routing cell. | 1,026 | `road_shortest_distance_study.ipynb` |

**Notes on coal plant data:**
- Filtered from the Global Energy Monitor Global Coal Plant Tracker (October 2025)
- Includes only plants with "operating" status (retired plants excluded)
- Excludes plants where `Coal type` is "waste coal"
- Deduplicated by `GEM location ID` — the source data tracks individual generating units, so multi-unit plants previously appeared multiple times at the same coordinates; the unit with the highest capacity is retained to represent each location
- Used as a proxy for fly ash supply source locations in geographic analysis
