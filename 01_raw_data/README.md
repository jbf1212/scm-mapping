# Raw Data Directory

This directory contains raw, unprocessed source files used in the SCM mapping analysis. Do not modify files here directly — see [`03_processing_scripts/`](../03_processing_scripts/) for the notebooks that generate and transform this data.

## Files

### EPD Data (`*.json`)

JSON files exported from the EC3 (Embodied Carbon in Construction Calculator) database via the `ec3-python-wrapper` API. Each record represents one concrete Environmental Product Declaration (EPD) and includes metadata on cementitious material composition, compressive strength, GWP, and plant location.

| File | Description | Records | Notes |
|------|-------------|---------|-------|
| `epd_data_all.json` | All US concrete EPDs across all compressive strengths | ~76,100 | ⚠️ Excluded from version control (file too large) — regenerate by running [`ec3_concrete_epd_gather_all.ipynb`](../03_processing_scripts/ec3_concrete_epd_gather_all.ipynb) |
| `epd_data_with_scm.json` | Subset filtered to EPDs that include SCM data (fly ash or GGBS) | ~5,000 | |

**Generated by:** [`ec3_concrete_epd_gather_all.ipynb`](../03_processing_scripts/ec3_concrete_epd_gather_all.ipynb)

### Coal Plant Data (`coal_plant_data/`)

**File:** `Global-Coal-Plant-Tracker-October-2025-Supplement-Proposals-outside-of-China.xlsx`

Comprehensive dataset of coal plant locations, capacities, and operational status for facilities outside China.

**Source:** [Global Energy Monitor – Global Coal Plant Tracker](https://globalenergymonitor.org/projects/global-coal-plant-tracker/)

**Citation:**
```
Global Energy Monitor, Global Coal Plant Tracker, October 2025 Supplement release.
```

**Processed by:** [`coal_plant_data_filtering.ipynb`](../03_processing_scripts/coal_plant_data_filtering.ipynb) → [`active_coal_plants_US.csv`](../02_processed_data/active_coal_plants_US.csv)
